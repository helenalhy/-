- [商場場景要求](mall-scene-requirements.md) — 狗狗服飾兌換後免費；花花獅子、糖糖小熊，魔法少女指定色與蕾絲公主裙要求詳見主題。
- [完全免費的金幣制度](free-economy.md) — 不課金、不儲值；只用完成目標獲得的金幣兌換，不能再要求獎勵券。
- [訪客體驗與進度同步](account-sync.md) — 登入不是使用門檻；保留訪客本機進度，登入時避免靜默覆蓋帳戶資料。
- [Expo 預覽快取](expo-preview-cache.md) — 舊頁或過早截圖會顯舊版／空圖；EADDRINUSE 時先檢查殘留 Expo 子程序。
- [商場讀屏結果回饋](mall-accessibility-results.md) — 分區切換依平台單一公告；窄版網頁標籤須驗證焦點與可視範圍同步。
- [商場路由回歸測試](mall-navigation-tests.md) — 元件測試替身不會自動渲染巢狀元件；路由測試須明確推進堆疊並渲染實際路由入口。
- [打卡與金幣原子性](checkin-atomicity.md) — 一次打卡同時更新完成狀態與金幣時，以單筆可恢復交易記錄避免跨儲存項目部分成功。
- [商場里程碑裝飾](mall-milestone-decorations.md) — 里程碑只解鎖符合原有樓層主題的裝飾；商場維持原有20層與主題。
- [每週補打卡獎勵](weekly-makeup-checkin.md) — 每帳戶每週可補昨天一次，補回時可領取原打卡金幣，但不重複發放。
- [動力功能獎勵界線](motivation-features.md) — 陪伴狗狗免費；計時不代打卡；最小行動推薦不覆寫自訂內容，也不更改每日通知。
- [巢狀讀屏標籤](nested-screenreader-labels.md) — 外層可按元件指定 accessibilityLabel 時，巢狀資訊須合併到外層標籤才會可靠播報。
- [商場讀取失敗](mall-read-failure.md) — 無法驗證已存資料時保留原始值、停止同步與變更，並顯示錯誤而非空商場。
- [手機網頁固定淺色](mobile-web-light-theme.md) — 手機瀏覽器須沿用 preview 糖果色，不隨作業系統切換深色。
- [彩妝試妝視覺驗收](cosmetics-tryon-visuals.md) — 試妝人像須保持臉至肩膀的大尺寸，並在已解鎖頁面目視確認唇色、眼影覆蓋正確位置。
- [手機網頁打卡推播](web-push-reminders.md) — 使用者需要關閉網頁後仍可收到每日提醒；訪客可用、可選時間，當日已打卡就略過。
- [Expo SVG 圖片資源](cross-platform-svg-assets.md) — SVG 明信片需用 expo-asset 取得跨平台圖片 URI，並避免 Hermes 不支援的字串 API。
- [狗狗店員圖片與互動](dog-staff-image-assets.md) — 名單與放大畫面同步切換；餵食用所選食物動畫、專屬玩具與飛盤互動保留狗狗原貌。
