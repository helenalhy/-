---
name: Expo 預覽快取
description: 長時間存在的網頁測試環境可能持續使用舊 JavaScript，不應誤判為程式未更新。
---

Expo 工作流程重啟後，長時間開啟的網頁測試頁可能在同一網址、一般重新整理後仍顯示舊版介面。新開的預覽截圖也可能在 Metro 提供的本地圖片載入前完成，造成背景或角色看似消失。

**Why:** 曾出現全新截圖已載入新功能，而保留的測試視窗仍顯示舊目錄；另有一次截圖早於商場背景及角色圖集載入。兩者都可能讓預覽看起來像程式未更新或場景缺圖。

**How to apply:** 做資料操作前先確認新版功能標記存在。若是空場景，先確認圖片資源能正常回應，並在固定的手機 viewport 等圖片完成載入後再判斷；若新舊視窗不一致，停用舊視窗的 HTTP 快取或改用新的隔離視窗。不要只憑過早截圖反覆修改場景程式。
