---
name: Expo 預覽快取
description: 長時間存在的網頁測試環境可能持續使用舊 JavaScript，不應誤判為程式未更新。
---

Expo 工作流程重啟後，長時間開啟的網頁測試頁可能在同一網址、一般重新整理後仍顯示舊版介面。

**Why:** 曾出現全新截圖已載入新功能，而保留的測試視窗仍顯示舊目錄；停用 HTTP 快取並重載後，新功能及保存流程均正常。這不是資料或程式回退。

**How to apply:** 做資料操作前先確認新版功能標記存在。若全新預覽與既有測試視窗不一致，先停用該測試視窗的 HTTP 快取，或改用新的隔離視窗，再繼續原本那一次驗證；不要因此反覆修改程式、重啟服務或重跑無關流程。
